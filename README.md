# STM32F411 Development Board

This project is a custom 4-layer STM32F411 development board designed in Altium Designer.

I built this board to improve my PCB design skills and take on something more challenging than the smaller projects I had done before. The goal was to design a complete STM32-based system and get more hands-on experience with schematic design, component selection, PCB layout, power regulation, and sensor integration.

---

## Major Components

| Component | Part | Purpose |
|---|---|---|
| Microcontroller | STM32F411 | Main processor |
| IMU | MPU-6050 | 6-axis accelerometer and gyroscope |
| Voltage Regulation | [Part Number] | Regulates input power to 3.3 V |
| USB Connector | [Part Number] | USB connection and power |
| SWD Header | [Part Number] | Programming and debugging |
| Crystal | [Frequency / Part] | MCU clock source |
